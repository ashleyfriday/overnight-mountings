# Overnight Mountings · Ring Builder

Step 1 of the ring builder ("Choose your ring style") with a live 3D ring on an Ionic pillar.
Everything visual — ring, diamond, pillar, logo, icons and card photos — is generated in code with Three.js.

## Features
- Drag to rotate the ring, scroll or pinch to zoom, 360° spin
- Split button lifts the diamond out of its setting
- Eight ring styles; card photos are rendered from the same 3D models

## Run locally
```bash
node serve.mjs
```
Then open http://localhost:5173. Three.js loads from a CDN, so an internet connection is needed.
